# kmeans
🎯 Customer Segmentation Using K-Means Clustering This project applies K-Means Clustering, an unsupervised learning algorithm, to perform customer segmentation based on features like income and spending score. The goal is to uncover natural groupings within the dataset, such as customer personas or behavior-based clusters.
🔍 Project Highlights
Performed exploratory data analysis (EDA) on customer dataset.

Visualized features like Annual Income, Spending Score, etc.

Applied Elbow Method to determine the optimal number of clusters (k).

Implemented K-Means using sklearn.

Visualized clusters using 2D plots.

📈 Techniques Used
Elbow Method for optimal cluster selection.

KMeans clustering from sklearn.cluster.

PCA (optional) for high-dimensional visualization (if applied).

Cluster visualizations via matplotlib or seaborn.

🗂️ Dataset
The dataset includes customer-related fields (e.g., Age, Annual Income, Spending Score).

Make sure it's named something like Mall_Customers.csv and placed in the working directory.
▶️ How to Run
Open the notebook ProjectKMeans.ipynb in Jupyter or any IDE.

Ensure the dataset is available in the same directory.

Run the cells step by step to see clustering results.
